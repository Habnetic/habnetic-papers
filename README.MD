# Habnetic Papers

This repository contains manuscripts and research documents produced as part of the **Habnetic** project.

Habnetic develops probabilistic frameworks for analysing decision stability in urban risk assessment under uncertainty.

## Contents

### Phase 1 – Rotterdam Decision Stability Baseline
Baseline methodological implementation of the Habnetic probabilistic risk framework.

Case study: Rotterdam (~221k buildings)

Files include:

- `paper_phase1_rtm_decision_stability.md` – manuscript source
- `paper_phase1.pdf` – compiled paper
- `figures/` – figures used in the manuscript
