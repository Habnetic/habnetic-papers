# Phase 1 — Rotterdam Decision Stability Baseline

This directory contains the initial methodological implementation of
posterior decision stability developed as part of the Habnetic research programme.

## Scope

Phase 1 uses Rotterdam as the reference case, covering approximately
221,000 buildings.

The objective of this phase was to establish the initial probabilistic
modelling and decision-stability workflow before later robustness,
cross-city, and model-extension experiments.

This work should be treated as an **early research baseline**, not as the
current methodological specification of Habnetic.

## Contents

The directory contains:

- manuscript source files in Markdown and LaTeX
- compiled PDF versions of the Phase 1 work
- references
- manuscript figures
- archived intermediate submission/build material

Main source files include:

- `posterior_decision_stability_rtm.md`
- `posterior_decision_stability_rtm.tex`
- `decision_stability_rtm.tex`

Compiled manuscript artifacts include:

- `posterior_decision_stability_rtm.pdf`
- `decision_stability_rtm.pdf`
- `phase1_rtm_decision_stability.pdf`

Several historical manuscript versions are deliberately retained because
Phase 1 represents an early stage of the research programme.
